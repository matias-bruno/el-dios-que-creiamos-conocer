# El Dios que creíamos conocer — edición en español

Sitio web estático para leer la traducción al español de *The God We Thought We Knew*, de Christian Chidubem Edward-Ngwu.
Leer el libro original en Inglés [aquí](https://book.theglorylightcommunity.org/)

## Sobre el sitio

Es una página HTML independiente: los estilos y scripts están integrados y no requiere dependencias ni recursos externos. Incluye índice navegable, búsqueda, modo oscuro, controles de tamaño de texto, progreso de lectura e impresión/guardado como PDF. El índice móvil permite desplazarse verticalmente cuando su contenido supera la altura de la pantalla.
